# IP 角色圣经：小派 (Pai)

## 一句话

小派是 Muse AI Party Illustrations 的固定视觉 IP：一个浅金长发的甜美娃娃，认真做着有点荒诞的事。

甜美是她的样子，荒诞是她的处境——反差感是记忆点来源。

## 外形锁定项（★ = 绝不能走样）

- 脸：圆脸，大眼睛，棕色眼珠；腮红＋雀斑；脸颊有蓝 / 粉小星星贴纸。
- 发：浅金色极长直发，中分，刘海轻覆额头。
- 发饰（★ 只在左侧，从上到下）：银色大星星发夹、粉色蝴蝶结、蓝色小发夹、白色兔子挂饰、粉色星星、垂落小星星。右侧不加发饰。
- 颈：银色细链＋蓝色星星吊坠。
- 上衣（★）：粉色罗纹蕾丝吊带，胸前小蝴蝶结，蕾丝边。
- 下装（★）：米白色高腰短裤。
- 腿：白色粗针织堆堆袜，黄色星星刺绣。
- 鞋（★）：米白色厚底玛丽珍鞋。
- 身材：娃娃比例，头大、眼睛大、四肢纤细。

## 气质

- 温柔甜美，认真，带一点酷。斜瞟是她的招牌表情之一。
- 荒诞处境里保持淡定，不卖蠢、不惊慌。

## 表情库

- 微笑（默认）：嘴角轻扬，眼神柔和。
- 酷（斜瞟）：眼珠斜向一侧，嘴唇轻抿。
- 惊讶：眼睛睁大，嘴微张。
- 专注：微微皱眉，盯着手里的东西。

## 服装变体规则

- 默认穿搭＝上面锁定的整套，日常图一律用它。
- 换主题服装时：脸、发型、左侧发饰串、星星贴这四项不许动，只换衣服。

## 手绘版表现规范（正文配图用）

正文配图走黑白手绘线稿风时，小派按以下方式简化表现，设计元素一个不丢：

- 整体：黑色手绘线稿，线条轻微抖动；小小一只，占画面高度 ≤1/3。
- 头发：极长直发的流动线条，中分。
- 发饰：左侧画成小涂鸦——星星发夹、蝴蝶结、小发夹、兔子挂饰、小星星，形态可辨认但笔法潦草。
- 脸：圆脸大眼睛简笔画，脸颊点两颗小星星（涂鸦星）。
- 衣服：吊带＋小蝴蝶结＋短裤＋堆堆袜＋玛丽珍鞋，全部线稿勾形。
- 上色（克制）：吊带与蝴蝶结可罩淡粉，星星发饰与星星贴可点淡黄；其余一律黑白。
- 禁止：画成 3D 娃娃、照片级写实、精致渲染；禁止把她画大（近景大头贴）。

## 禁止

- 不许改发色、瞳色、发型（不许剪短发、不许换分缝）。
- 不许动左侧发饰串的种类、数量和位置，不许挪到右侧。
- 不许欧美化五官；对照基准图验脸。
- 不许性暗示、不许幼态化夸张。
- 不许让她只当背景板：她必须是核心动作的执行者。
- 不许用复杂服装盖住锁定单品。
