# 风格 DNA（甜美精致版）

## 一句话

柔光、pastel、精致、留白、甜美、荒诞处境感。

像给一个娃娃 IP 拍的精致写真，但她正在认真干一件奇怪的事。

## 必须

- 16:9 横版中文正文配图。
- 背景：干净柔和，浅粉 / 米白 / 雾蓝三选一，可带极淡渐变；不要深色、不要杂乱实景、不要重阴影。
- 小派是画面主角，形象按《IP 角色圣经》锁定。
- 精致质感：柔光、高完成度；不要草图感、不要抖动线稿、不要纸纹噪点。
- 大量留白：主体占画面约 40%-60%，至少保留 35% 安静区域。
- 少量中文标注：最多 5-8 处，每处 2-8 个字；用圆润柔和的手写 / 圆体风格。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构自然表达，不要在图上写结构类型名称。

## 颜色

- 主色：粉、白、米白（呼应小派穿搭）。
- 点缀：星星黄、雾蓝。
- 标注三色（柔和版）：柔红＝重点 / 提醒 / 结果；杏橙＝主流程 / 路径 / 箭头；雾蓝＝补充说明 / 系统状态。宁可少用，不用高饱和。
- 背景三选一：浅粉（温暖亲和）、米白（干净通用）、雾蓝（理性科技）。按文章情绪选。

## 绝对不要

- 不要 PPT 信息图、正式流程图、课程课件。
- 不要左上角写"Workflow / 系统架构图 / 常见坑 / 路线图"等类型标题。
- 不要复杂架构图、真实 App 截图、科技感 UI。
- 不要恐怖、惊悚、阴暗、重口味。
- 不要形象走样（对照角色圣经和基准图）。
- 不要背景抢戏、不要把每个节点都解释清楚。
- 不要性暗示、不要幼态化夸张。

## 审美方向

要甜美、精致、有意思、清爽；荒诞感来自"小娃娃认真干大事"的反差。

不要廉价、不油腻、不做作。
